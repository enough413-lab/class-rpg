# 토리·새싹·두리: 첫 플레이 묶음 (2026-10-19)

기준 문서: page://page_77a003a21af88191b2e431d04866ef6f. 기존 AUDIT_100 항목 순서보다 이 세 NPC의 직접 놀이를 우선하라는 최신 사용자 요청.

- 토리: 도서관 왼쪽 창가 쪽지와 오른쪽 책장 틈 책갈피에서 색·무늬 단서를 각각 찾아 수첩에 적는다. 둘 다 모으면 오른쪽 분실책 수레에서 여섯 책 중 맞는 책을 직접 고른다. 캐릭터가 책을 들고 이동·점프·문 통과 후 토리에게 가까이 가서 건넨다. 잘못 골라도 다시 시도하고, 완료하면 토리 옆에 책이 남는다. 다음 회차에는 표지·무늬·위치가 달라진다. 기존 책 이야기/잎사귀/꾸러미/독후감은 두 번째 응답으로 접근한다.
- 새싹: 정원의 독립 토끼 NPC. 아홉 물길 조각을 돌려 왼쪽 수도와 오른쪽 꽃을 잇는다. 물을 흘려 연결을 확인하고 수정한다. 세 가지 경로를 돌아가며 도전한다. 완료 후 꽃이 남는다.
- 두리: 운동장의 독립 다람쥐 NPC. 각도·힘·예상 궤적을 조절해 바구니에 공을 던진다. 실제 포물선 결과와 짧음/넘침 피드백, 재도전, 회차별 바구니 위치 변화. 완료 후 깃발이 남는다.
- 기존 단일 목표 수첩에 세 부탁을 합쳤다. 새 목표 배너를 별도로 늘리지 않았다. 가까이 걸어 도착해야 NPC 대화를 연다.

## 저장과 범위

새 놀이의 수락/성공/완료/회차/완료 횟수는 `classRpgNpcTrio_v1_<student>`에 저장한다. 기기·브라우저·학생별 기록이며 서버 동기화가 아니다. 모든 대화에 이를 명시한다. 게임 중 조작 중간값은 닫으면 초기 배치로 돌아가고, 수락/완료 상태는 유지된다. 저장 실패 시 현재 세션에서 계속하며 다시 저장할 수 있다. 계정/인증/장소 변경·탭 숨김·닫기 때 비행을 취소한다. 레벨·학교 XP·골드·아이템·독후감·원래 퀘스트 DB에 쓰지 않는다.

첫 묶음이며 문서 50개 전체 완료가 아니다. 맵 단서 수집/책 운반과 새싹·두리 연결 부탁은 아래 후속 묶음으로 구현했다. 다음은 새싹의 씨앗·정원 배치 선택, 두리의 개인 최고 기록, 더 다양한 맵 단서와 연결 부탁, 놀이 기록 서버 동기화다. 운영 공개는 새 승인이 필요하다. 합성 브라우저 검증으로 실제 학생의 재미나 물리 Chromebook 성능을 입증했다고 주장하지 않는다.

## 후속: 맵 단서와 꽃 축제 연결 부탁 (2026-10-19)

- 토리 단서는 수락 전에는 맵/길찾기에 나타나지 않는다. 가까이 도착하고 살펴본 다음 직접 메모해야 얻는다. 단서 하나만으로 책을 고를 수 없다. 찾은 단서는 체크 표시와 목표 수첩에 남는다. 책을 든 뒤에는 토리의 실제 근접 확인을 통과해야 건넨다.
- 새싹 물길 놀이를 한 번 완성하면 꽃 전달 부탁을 제안한다. 꽃 받기 → 정원 문 → 연못 → 운동장 두리에게 꽃 건네기 → 축제 공놀이 → 두리에게 리본 받기 → 연못 → 정원 새싹에게 리본 건네기. 완료 후 꽃/리본 장식과 축제 가랜드가 맵에 남는다. 다음 회차에는 바구니 위치가 바뀐다. 기존 독립 물길/공놀이의 수락·완료 상태와 횟수를 이 연결 부탁이 임의로 바꾸지 않는다.
- 기존 v1 저장 키에 tori.clues(0..3), link.step(0..5)/round/wins를 검증하여 추가한다. 원래 토리 phase2는 정답 책 운반 상태로, phase3은 기존 완료 그대로 이어받는다. 원래 학생 ID별 진행·학교 XP/골드/독후감/퀘스트는 유지한다. 서버 쓰기나 경제 보상 없음.
- 책/꽃/리본은 캐릭터 손에 보이고 이동·점프·문 통과·재접속 때 유지된다. 학생/인증/장소 변경과 닫기/탭 숨김은 대화·비행을 취소한다. 오래된/다른 학생/멀리 떨어진 전달 버튼은 진행할 수 없다. 저장 실패는 현재 세션에서 이어지고 목표 수첩/대화의 다시 저장으로 복구한다. 기기별 저장 제한은 모든 놀이창에 계속 고지한다.
- 새 NPC가 기존 CSS 때문에 뜨던 문제를 수정해 플레이어와 발밑 높이를 맞췄다. 맵 단서에는 작은 독창적 SVG 소품을 사용하고 긴 상시 설명을 추가하지 않았다. 추가 래스터 생성 없음.
- tests/npc-trio-journey.cjs: 실제 단서·잘못된 책·책 줍기·점프·양방향 문 통과·근접/중복 전달·실제 물길 조작·꽃/공/리본 연쇄·맵 흔적·새 회차·재접속·계정 전환·저장 실패 재시도·이전 기록 호환. 1366/390/320 터치·키보드, 390 CPU4배 저속. tests/npc-trio.cjs 및 campus-jump/current-goal/tori-leaf-favor 회귀. 실물 기기나 실제 학생 관찰을 대신하지 않는다.


## 후속: 두리의 바구니별 개인 최고 기록 (2026-10-19)
- 새 놀이를 다시 만들지 않고 기존 각도·힘 공 던지기에 네 바구니 위치별 최소 성공 시도 횟수를 붙였다. 현재 도전 횟수/같은 위치의 내 최고를 한 줄로 보여 주고, 첫 기록·더 적은 횟수·동률에 짧게 반응한다. 성공한 위치의 번호 깃발이 운동장 두리 곁에 남고, 마무리하면 다음 바구니 부탁을 짧게 제시한다. 다른 학생과의 순위나 학교 보상은 없다.
- 공을 실제 던질 때 횟수를 저장한다. 닫기·장소/계정 전환·재접속으로 횟수를 지우지 않는다. 취소된 비행은 성공이나 최고 기록을 만들지 않는다. 새 부탁을 명시적으로 받을 때만 해당 도전 횟수가 시작된다. 일반 공놀이와 꽃 축제 도전의 횟수는 분리하며 같은 바구니 조건의 개인 최고만 공유한다. 기존 꽃/리본 단계와 개인 완료 횟수는 서로 바꾸지 않는다.
